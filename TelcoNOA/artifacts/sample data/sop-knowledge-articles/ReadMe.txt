Affirmed Networks User Guides and Release Notes for Release 9.4.0.0 - Indexed Adobe PDF Documentation Set
=========================================================================================================

An Adobe PDF indexed documentation set allows users to search for words and phrases in all documents from a single search window. 

To search the entire documentation set, you must first download the Affirmed_Networks_9.4.0.0.zip file, extract the contents, and retain the existing folder structure. If you move, delete, edit, or replace a file, you will no longer be able to use the index to search that file.

Note: You must use Adobe Acrobat or Adobe Acrobat Reader to open the index file.

Use the following steps to search the documentation set:

1. Double-click the _Affirmed_Networks_9.4.0.0_Index.pdx file (not folder).
2. In the Search window, make sure that "In the index named Affirmed_Networks_9.4.0.0.pdx" is selected.
3. Enter the word or phrase in the search dialog box.
4. Select any optional filters.
5. Click Search. 

Notes:
- Numbers are included in the index
- All words are included in the index
